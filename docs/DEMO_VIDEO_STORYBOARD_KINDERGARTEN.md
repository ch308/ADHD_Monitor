## 演示叙事

1. **教室日常**：刘老师巡视引导手工，三名学童分坐小桌，手环静默常亮（蓝/橙/绿，约20%亮度）。
2. **陈同学心率升高**：情绪波动，重复动作加快，腿部抖动；手环橙色光晕悄然加深（20%→60%），脉冲扩散一圈。
3. **刘老师手环静默提示**：左腕橙色脉冲振动，无声；刘老师余光一瞥手腕，无需掏手机。
4. **温柔赶到**：轻步走向陈同学，蹲下与他视线平齐，手轻搭肩膀。
5. **陈同学平静**：腿部抖动停止，肩线下沉，手环橙色光晕缓缓变淡（60%→30%），色温从纯橙偏向暖黄。
6. **其余学童安然**：杜同学、林同学手环安静，教室其他角落正常——精准响应，不打扰全班。
7. **落版**：「一个老师，守护每一颗星星。」

## 分镜统一风格锚点（各镜共用）

| 项 | 约定 |
|---|------|
| **影像气质** | 温情纪实 + 轻微纪录片感；写实肤质与织物纹理；儿童表情克制真实，不做哭闹夸张脸 |
| **色温** | 教室自然窗光为主（约4800–5500K），弱暖反射；手环报警时引入对应颜色极窄光晕，占画面≤10% |
| **对比与颗粒** | 中低对比，暗部微微抬起；极轻胶片颗粒（全片统一） |
| **景深** | 浅景深突出当前主体；广角建立镜保留景深层次；T05为全片最浅景深 |
| **运镜** | 以慢推、静止长镜、轻微手持感为主；刘老师走动用平稳跟焦 |
| **颜色铁律** | 蓝=杜同学，橙=陈同学，绿=林同学，黑=刘老师；同一镜内绝不混淆 |

**场景一致性规则**（见 `AIGC_ASSET_PROMPTS_KINDERGARTEN.md §〇`）：所有教室镜头须以**场景母版图**为 Image Reference；每条提示词开头粘贴**场景锁定段落**；P6红色积木按**跨镜位置锚点表**逐镜指定状态。

| **① 轻步赶到** | 约1–2s | 刘老师从画面左侧轻步入画，脚跟先落地，步伐平稳；左手微摆，手环橙光极淡隐约可见；面部沉静，视线已锁定陈同学方向。 | 跟焦平稳跟拍，背景虚焦流动 |

### 合规与风险提示

- **儿童形象**：陈同学/杜同学/林同学均为AI生成虚构儿童，非真实人物；提示词中已排除可识别面孔特征复制
- **ADHD 行为描写**：行为描写基于 ADHD 典型症状（腿抖、手部刺激寻求、专注困难），不涉及诊断标签展示
- **监控语感**：全片避免「监控」「警报」等词，以「守护」「关注」「老师来了」为核心表述
- **手指变形风险**：T04③/T05①手部特写须在负向词中加强 `distorted hands, extra fingers`
- **长镜头超上限**：T04（6–8s）/T05（7–9s）均拆段生成，见操作速查表
