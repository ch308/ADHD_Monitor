# AI 大赛演示片（幼儿园教师模式）— AIGC 资产与道具提示词清单

> **对应分镜稿**：`docs/DEMO_VIDEO_STORYBOARD_KINDERGARTEN.md`

## 全局规则

**风格**：真人实拍写实摄影，温情纪实，轻微纪录片感，自然肤质与织物纹理，非动画、非插画、非3D渲染，儿童表情克制真实，中低对比，极轻胶片颗粒，浅景深

**定妆图背景**：角色与道具单品图一律**纯色纯白背景**，便于抠像

**统一负向词**（每条提示词均追加）：`动画、卡通、插画、3D渲染、CGI、塑料质感、娃娃感、手指变形、多余手指、文字乱码、哭泣夸张表情、霓虹过饱和、整帧变色`

**颜色码铁律**：蓝=杜同学，橙=陈同学，绿=林同学，黑=刘老师；跨镜不得串色，生成前一次性定案

**手环屏幕**：屏幕区域保持深色常亮低光状态，无需显示数字或文字；报警状态以光晕亮度与边缘脉冲颜色区分，无后期贴字需求
