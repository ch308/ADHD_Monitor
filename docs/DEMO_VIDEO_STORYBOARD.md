# AI 大赛演示片 — 分镜稿（温情向）

> 产品定位：**充满温情与关爱的陪伴**，弱化「监控」语感；画面与字幕优先使用「陪伴」「关注」「一起呼吸」等表述。  
> 与实机工程差异（长轮询 / 手机端音频等）见文末「成片与实机」说明。**分镜风格一致性与各镜扩写**见 **「分镜统一风格锚点」** 与 **M01～M09** 表格。

---

## 全片基调

- **气质**：温暖、克制；科技服务于人，不冰冷。  
- **色板**：书桌冷白台灯 + 题纸灰白；焦虑段略压暗；治愈段转**琥珀金**主光。  
- **节奏**：前段渐紧 → 云端联动利落切镜 → 三端齐发 → 手环数字缓和收尾。

## 人物设定（定妆参考）

> **用途**：在生成视频前，先为 **孩子**、**父亲**、**母亲** 各出若干张 **定妆图**（建议：半身正面、45° 侧面、书桌场景中景各 1 张），全组选定后，**后续每一条文生图 / 图生视频 Prompt 都在开头粘贴「人物锁定」段落**，减少多镜头脸崩、换装漂移。  
> **手环与穿衣**：手环 **佩戴手、表带颜色、表盘形状** 全片固定；T恤恐龙图案 **形状与颜色** 固定，避免每镜恐龙长得不一样。  
> **与分镜衔接**：各镜 **面部特写、光比与运镜** 已扩写在后文 **「分镜统一风格锚点」及 M01～M09**，出图时请与本文 **人物锁定** 一并遵守。

### 孩子（三年级男孩）

| 维度 | 详细描述（可直接拆进 Prompt） |
| --- | --- |
| **年龄与体态** | 约 **9～10 岁**，小学 **三年级**；身高、体型符合同龄 **偏标准或略瘦**，肩偏窄，**手腕细**（便于手环特写与 HUD 可读）。 |

| **衣着** | **白色圆领短袖 T 恤**，版型略宽松、领口罗纹清晰；**胸前印有卡通恐龙图案**——建议固定为 **侧脸行走的绿系或蓝灰系恐龙**、**扁平插画风格**、面积约占胸前 **1/3**，不要每镜更换恐龙姿态。下装建议固定为 **深蓝或炭灰运动长裤**（或及膝运动短裤二选一，**全片只选一种**）。脚上若入画：**灰色家居拖鞋** 或 **白袜**，勿混用。 |
| **配饰与动作** | **左手腕**佩戴 **窄款深色表带** 或 **浅色方形表盘** 智能手环（二选一，**全片固定**）；写字时 **右手握笔**（铅笔或中性笔），坐姿可 **略前倾**、肘撑桌沿，**不驼背夸张**。 |
| **气质** | 平时安静、遇难题时 **困惑与焦虑** 写在脸上，**不哭闹夸张**；整体符合「普通家庭里会写作业的孩子」。 |

## 演示叙事：终极形态（场景总述）

> 面向 **投资人与家长** 演示时的「终极形态」叙事：采用 **腾讯云** 承载数据与联动策略后，系统可在同一时刻把 **体征、家庭与两台陪伴硬件** 拉进一条闭环，画面冲击力强。  
> **与分镜对应**：下列 1～3 步大致对应 **M01～M08**；口播落版见 **M09**。动画为表现可略夸张；与当前仓库实机差异见文末 **「成片与实机」**（如 MQTT 文案 vs 长轮询、432Hz 与灯效关系）。

1. **书桌焦虑**：孩子戴着手环在书桌前写数学题，遇难题开始焦虑；手环侧显示心率 **115**（可用数字动画或 HUD 强调）。
2. **静默上云**：手机 App **不打扰孩子**，在后台将数据同步至 **腾讯云**（可用粒子流、云图标等抽象表现，避免过度绑定未授权 UI）。
3. **腾讯云激活联动**（三端同发，可快切或分屏）：
   1. **家长端**：隔壁房间父母的手机收到推送并开始震动（温和通知，非刺耳警报）。
   2. **毛绒球**：书桌上的 **微雪毛绒球** 收到云端指令，**瞬间亮起**治愈的**琥珀色暖光**，并缓缓淡入 **432Hz 钢琴曲**（可用音波可视化表现「声光一体」）。
   3. **星星机器人**：同时收到指令，**表情灯闪烁**，以特教老师般温柔语气主动开口：「小主人，写作业累了吧？我们先和毛绒球一起深呼吸三次吧。」

**一句话收束**：这是 **物联网 + 特教 AI** 的全方位闭环，也是产品希望对外传达的 **终极形态与核心壁垒**。

## 分镜统一风格锚点（各镜共用）

全片生成（文生图 / 图生视频）时 **每条 Prompt 除人物锁定外**，建议重复或化用下列锚点，减少「有的像纪录片、有的像广告」的跳tone：

| 项 | 约定 |
| --- | --- |
| **影像气质** | **温情纪实 + 轻微电影感**；写实肤质与织物纹理；避免过度磨皮、避免网红滤镜；儿童表情 **克制真实**，不做夸张鬼脸。 |
| **色温** | 孩子书桌：**中性偏冷台灯主光**（约 4800–5600K）+ 环境弱暖反射；焦虑镜（M02）可 **整体降 1/4 档曝光**；治愈段（M06 起）引入 **琥珀金**（约 2800–3500K）与冷台灯的 **小面积对比**，不要整屏糊成单色。 |
| **对比与颗粒** | 中低对比、暗部 **微微抬起**（保留细节，不死黑）；可带 **极轻胶片颗粒**（统一一种，全片一致）。 |
| **景深** | 以 **浅景深突出主体**（孩子脸 / 手环 / 毛绒球 / 父母脸）为主；全景时景深略收，仍保持层次。 |
| **运镜** | 以 **慢推、轻摇、静止长镜头** 为主；除 M02、M08 外 **少用急甩镜头**；全片 **无手持剧烈晃动**（可用极轻 stabilized micro-movement）。 |
| **人物** | 孩子与父母 **须与《人物设定》定妆一致**；同一镜内 **五官比例、发型分区线、T恤恐龙轮廓** 与定妆图对齐。 |

### M01｜建立场景（约 3–4s）

| 项目 | 内容 |
| --- | --- |
| **风格锚点** | 沿用上一节「温情纪实 + 轻微电影感」；整体情绪 **平静中藏一丝不易察觉的紧张**（为 M02 铺垫）。 |
| **场景与环境** | **夜晚或傍晚**，孩子房间；实木书桌略凌乱：**数学练习册翻开**、草稿纸一条数式写到一半、橡皮屑一两点、铅笔一支；台灯在画面 **左或右前侧 45°**，灯臂略入画；背景书架 **虚化成色块**，可辨几本书脊；**毛绒球在桌角近镜头侧**，此刻 **无灯全暗**；星星机器人在 **景深远端** 小轮廓，无强发光。 |
| **人物与动作** | 男孩 **坐姿略前倾**，**右肘撑桌**、**右手握笔**停在题目旁，似在思考；**左手自然平放**或轻搭桌沿，**手环朝上** 便于后续 HUD。视线落在题面 **略偏下**，尚未崩溃。 |
| **面部特写** | 以 **中近景 → 缓慢推至胸上脸下** 为主；面部光 **台灯侧光**：**近灯侧颊** 略亮、**远灯侧** 柔和阴影；**眼睛**：黑褐色虹膜清晰，眼神 **专注略带迟疑**；**眉** 轻蹙未拧死；**嘴** 自然闭合，嘴角 **平直略下** 1mm 级即可；**鼻翼** 随呼吸几乎不可见地起伏；皮肤 **细小毛孔与浅绒毛** 保留，忌瓷娃娃肌。 |
| **运镜与节奏** | **稳定缓慢前推**（dolly-in），0.3～0.5 单位速度；结尾 **半秒静止** 落在眼与眉之间，给观众「他在使劲想」的停顿。 |
| **光色与氛围** | 主光台灯；环境 **弱环境反射**（白墙映一点暖）；**不压黑四角**，保留房间「安全屋」感。 |
| **道具与界面** | 手环屏或玻璃反光：**极淡「陪伴中」**，字重轻、像呼吸灯亮度 **30～40%**，勿抢脸。 |
| **音效** | 铅笔尖轻划纸、远处 **极弱** 钟表滴答；无配乐或 **几乎不可闻** 的铺底。 |
| **AI 提示词（示例）** | 首行：**人物锁定（孩子）**；接：**cinematic documentary, warm restrained grade, Chinese home study at night, cool desk lamp key light, shallow depth of field, boy thinking at math homework, plush toy dim on desk corner, smart band shows faint Chinese 「陪伴中」, 4K photorealistic, subtle skin texture, slow gentle dolly in, no horror, no exaggerated face** |

### M02｜遇难题焦虑（约 4–6s）

| 项目 | 内容 |
| --- | --- |
| **风格锚点** | 情绪 **收紧但不惊悚**；允许 **极短** 主观化（M01 末半拍可接 M02 第一拍轻微失焦再拉回）。 |
| **场景与环境** | 仍为孩子书桌；练习册同一页，可 **铅笔尖顿在纸上压出一小墨点**；台灯仍在，但 **整体曝光比 M01 降 1/4 档** 或台灯略 **提高对比**（焦虑来自光比，而非变色温乱飘）。 |
| **人物与动作** | 笔停 **2 秒级**；另一手 **无意识抠拇指侧** 或轻揉太阳穴（二选一，全片若用抠指则后镜保持同一习惯）；肩 **微耸**。 |
| **面部特写（重点）** | **特写 → 极特写** 两级：① **眉间**：眉心出现 **浅竖纹**，双眉 **内角略抬**；② **眼**：眼睑 **微颤一下**，瞳孔略散、**高光点略碎**（像泪膜不稳但 **不哭**）；③ **鼻翼**：一次略深的吸气后 **略张**；④ **嘴**：下唇 **轻顶上门牙内侧** 又松开，或 **嘴角下拉 2～3mm**；⑤ **下颌**：咬肌 **微紧** 一条线，松手即消。若有 **1/4 侧面**，可见 **耳根到颈** 细小汗毛因紧张略立（极淡即可）。 |
| **手环与 HUD** | **切镜到手环大特写**：数字从 **78～90 区间快速升至 115**（数字字体固定一款）；数字边缘可做 **极轻 pulse**，勿霓虹闪烁；可加 **半透 HUD 弧线** 套在数字外，仍偏「陪伴」而非「急救」。 |
| **运镜与节奏** | 脸特写：**微推近 + 极短 duration 的 micro shake**（2～4 帧）模拟生理紧张，随即 **稳态**；切手环可用 **quick cut** 或 **snap zoom** 一次即止。 |
| **音效** | **低频一次「咚」**（60–80Hz）像心跳沉一下；环境 **抽离 1～2dB**、高频略柔；仍无旋律。 |

### M03｜数据上行：App → 云（约 5～7s）

| 项目 | 内容 |
| --- | --- |
| **风格锚点** | **安静、克制、科技感不冰冷**；与 M01–M02 同一颗粒与对比曲线；本镜 **孩子可不占主画面** 或仅 **背影/虚焦侧脸** 一角，避免与 M02 表情链断裂。 |
| **场景与环境** | 书桌一角：**手机平放或斜靠书立**，屏幕亮度 **中低**，勿全黑机房感；背景孩子 **虚焦** 仍在写字，形成「**世界在后台运转**」；抽象层：**细粒子光带** 从手机屏缘升起，经窗框一角 **弯向「云」意象**（几何粒子云 / 柔边腾讯云青白，避免未授权 UI）。 |
| **人物与动作** | 若带到脸：**仅侧脸剪影或虚化轮廓**，表情 **维持 M02 末的低落** 即可，不再升级情绪。手部可选：**指尖离开屏幕** 表示非交互上传。 |
| **面部特写** | 本镜 **不以面部为主**；若坚持出现孩子眼：**半格倒影** 映在手机屏 **波形曲线** 上，眼神仍略散。 |
| **运镜与节奏** | **双图层合成感可控**：实景慢推 + 粒子层 **缓慢漂移**；粒子速度 **低于** M04，表示「静默」而非「警报」。 |
| **光色** | 手机光 **冷青偏蓝** 一点（数据感），与环境 **暖弱光** 形成 **小面积互补**，面积比约 **3:7**（环境大、屏幕小）。 |
| **字幕（可选）** | 「孩子的状态已同步至云端，**家人与陪伴设备将温柔响应**」；字体 **圆角无衬线**、字重中等，**不红不闪**。 |
| **音效** | **极轻「光纤式」上升音** 1～2s；无警报、无语音播报。 |
| **AI 提示词（示例）** | 人物锁定（孩子）可弱化或仅背影；**soft sci-fi data stream, gentle particles rising from smartphone, subtle Tencent cloud motif abstract, warm dim room, out-of-focus child studying, calm tech, cinematic, 4K, no harsh UI, no stock ticker vibe** |

### M04｜云端「联动」总控（约 3～4s，可选）

| 项目 | 内容 |
| --- | --- |
| **风格锚点** | **抽象 UI / 信息可视化**，勿做成战争指挥室；色与 M03 云粒子 **同一青白 + 少量琥珀点缀**（预演 M06 色）。 |
| **场景与环境** | 虚拟「塔台」界面：**三条柔光链路** 从中央节点射向三个图标——**云策略 → 双手机剪影 → 书桌灯泡/毛绒球剪影**；中央 **一行短文案** 快闪即可。 |
| **人物** | 可无真人；若有 **剪影侧脸**，仅作 **图标化** 处理，避免与定妆冲突。 |
| **面部特写** | 一般 **不需要**；若混剪真人 **≤0.5s** 快闪，用 **已选定的定妆侧脸** 勿新生脸。 |
| **运镜** | **慢旋转 5°** 或 **中心放射渐显**；节奏 **利落但不快剪炫技**。 |
| **音效** | **三下递进「叮」** 和弦，音量 **低于** M05 震动。 |
| **文案** | 「**陪伴联动已触发：安抚 + 同在**」 |

### M05｜父母手机（约 5～6s）

| 项目 | 内容 |
| --- | --- |
| **风格锚点** | **卧室私密、暖、轻倦意与关切并存**；与《人物设定》父母定妆 **同一睡衣与发型分区**。 |
| **场景与环境** | **隔壁卧室**：床头 **暖黄小台灯**，被单 **亚麻色或浅灰**；床头柜 **水杯半满**、书一本倒扣；手机在 **父亲或母亲掌心**（与分镜 storyboard 一致谁主握）。 |
| **人物与动作** | **并排靠坐** 或 **一坐一半躺**；先 **各自看手机** → 震动后 **同时抬眼** → **对视半秒** → 母亲 **指尖在屏上滑一下** 确认通知详情。 |
| **面部特写（父亲）** | **中近景**：**眼下淡黑眼圈** 在暖灯下 **不脏**（倦意来自作息，不靠皱纹刻画）；**眉** 从放松到 **略抬**；**眼** 瞳孔 **微微放大** 读屏；**面颊与法令区域保持平滑干净**，**不加深法令纹、不强调胡茬**；**嘴** 从微张读字到 **抿成一条** 表示「嗯，得看看」。 |
| **面部特写（母亲）** | **中近景**：**眉心轻蹙** 一瞬即松；**眼** 先看屏再看配偶，**眼角软下来**；**嘴角** 先 **下撇 1mm（担心）** 再 **略上扬成安慰式**（对配偶而非笑场）；**颊** 暖光下 **略红** 可来自台灯反射而非腮红。 |
| **手机与推送** | 横幅：**温和图标**（小月亮 / 小叶子 / 心形线稿）+ 文案「孩子可能需要你陪一下」；**勿红色全屏警报**；屏幕光 **映在两人鼻梁与颧骨** 形成 **窄条高光**。 |
| **震动表现** | **水杯同心细涟漪**；被单纤维 **几乎看不见的颤**；掌根与手机边框 **1mm 级位移** 即可。 |
| **运镜** | **正反打**：手机特写 → 父亲脸 → 手机 → 母亲脸；**每切一次光方向不变**（台灯在画面固定侧）。 |
| **音效** | 手机 **两声短震「嗡—嗡—」**；通知音 **极轻**；卧室 **环境底噪极低**。 |
| **AI 提示词（示例）** | 首行：**人物锁定（父母）**；**warm bedroom, practical lamp light, East Asian couple mid-late 30s, father with neat black hair smooth youthful face no gray no stubble emphasis, mild under-eye tiredness only, gentle concern reading phone, mother natural, smartphone notification glow on faces, subtle water ripple in glass, cinematic shallow dof, photorealistic skin, no aging makeup, no melodrama** |

### M06｜毛绒球（约 6～8s）

| 项目 | 内容 |
| --- | --- |
| **风格锚点** | **治愈、有机、呼吸感**；与 M01 冷台灯 **同处一桌** 时，注意 **冷暖并存**（球暖、环境仍可有冷边）。 |
| **场景与环境** | 书桌 **同一机位或略换角度**；数学纸仍在画面边缘 **提示连续性**；毛绒球 **织物纤维清晰**，缝线走向固定；球体由 **全暗 → 内透光渗出** 像有「小灯芯在绒毛里」。 |
| **人物与动作（可选入画）** | 孩子 **不出正脸也可**：仅 **入画下巴到肩** 或 **眼神余光被光吸引** 的微动；若出正脸，表情从 M02 焦虑 **松一线**：**眉心纹略展、嘴唇微启**。 |
| **面部特写（若拍孩子反应）** | **侧 45° 近景**：琥珀光 **扫过面颊一侧**，形成 **窄金色高光线**；**眼**：瞳孔里 **映出一小块圆形暖光**（球体反射）；**嘴角** **放松** 不必微笑。 |
| **光色与动效** | **琥珀金** 主色 **#C9A227～#E8B84D 区间**（全片固定色带）；呼吸周期 **4～6s 一循环** 与后期钢琴节奏对齐；可选 **极淡音波环** 从球心扩散，透明度低。 |
| **运镜** | **慢绕球 10～15°** 或 **微推**；避免快速旋转玩具感。 |
| **音效** | **极弱低频嗡** 起光瞬间；**432Hz 钢琴** 稀疏单音 **渐入**（音量曲线 **3s 渐起**）。 |
| **AI 提示词（示例）** | **macro plush smart lamp on study desk, fabric texture, warm amber inner glow breathing, gentle light spill on homework paper edge, cinematic, photorealistic, slow subtle camera move, healing mood, no toy commercial sparkle overload** |

### M07｜星星机器人（约 7～9s）

| 项目 | 内容 |
| --- | --- |
| **风格锚点** | **温柔、特教感、无恐怖谷**；机器人屏幕脸 **简化几何**（大圆眼弯线嘴），表情变化 **慢、幅度小**。 |
| **场景与环境** | 仍在孩子桌 **侧后方或斜上**；背景 **浅景深**；M06 琥珀光 **在机器人外壳边缘** 可勾 **细轮廓光**（与球联动）。 |

| **面部特写（孩子）** | **近景侧脸**：**耳朵朝机器人一侧** 略红（被台灯+屏光染）；**眼**：视线 **从题面移到机器人** 时 **高光点从散到聚**；**嘴**：可 **随机器人台词做极轻微同步开合**（不必对口型完美）。 |

| **台词与字幕** | 「小主人，写作业累了吧？我们先和毛绒球一起深呼吸三次吧。」字幕 **圆角大字**、**米白描边深褐字** 或反色，**2 行内**。 |
| **运镜** | **轻仰角** 看机器人（增强「陪伴者」高度感但 **不压迫**）；反打孩子侧脸。 |
| **音效** | **女声温柔慢语速**（特教老师气质）；底噪 **干净**；句尾 **略降调** 安定感。 |
| **AI 提示词（示例）** | 孩子侧脸用人物锁定；**cute desktop robot with simple screen face, gentle LED expression, warm bedside study, child profile listening, soft amber rim light, kind teacher-like tone implied visually, cinematic, no uncanny valley, slow blinking face UI** |

### M08｜闭环蒙太奇（约 6～8s）

## 文生图 + 图生视频：平台怎么定

推荐工作流：**文生图**固定人物与道具 → **图生视频**只做小幅运动，可控性高。各站模型与定价变化快，以官网为准；定稿前用**同一分镜图**在候选站上各试几条再选。

### 选型前确认

| 维度 | 说明 |
| --- | --- |
| **授权** | 大赛投稿 / 公开展播若要求 **可商用**，须核对各站会员协议中的 **比赛 / 宣传** 条款。 |
| **画面** | 本片需 **画面内中文**（手环「陪伴中」、推送等）；复杂推拉摇移镜头少，不必为运镜单独上国际站。 |
| **预算** | M01–M09 每镜按 **3～5 次抽卡** 预留积分；**约 200 元且只开一个站** 时见下节二选一。 |

### 即梦 vs 可灵：二选一（约 200 元人民币）

**总预算约 200 元**或**只开一个会员**时：**选 [即梦](https://jimeng.jianying.com/)** 单站完成文生图 + 图生视频，再用 [剪映](https://www.capcut.cn/) 剪辑。

| 即梦 | 可灵 |
| --- | --- |
| 主体、构图相对稳，**单位预算下可用条数通常更多**。 | 运镜与动态张力常更强，**重抽与积分消耗往往更大**。 |
| **画面内小字中文**（陪伴中、推送）更省心。 | 适合「少而精」的高光镜，不宜作唯一交片站（在紧预算下）。 |
| 与剪映同源，**导出剪辑链路短**。 | 与即梦 **同图对比** 择优时作辅站更佳。 |

**二选一选可灵的前提**：团队明确优先 **强运镜 / 强动态**，并接受 **成片条数变少**。本片以温情、中文 HUD、小幅运动为主，**默认即梦**。

**预算可双开时**：即梦跑通全片；[可灵](https://klingai.kuaishou.com/) 仅做 **2～3 个高光镜**（如 M06 琥珀呼吸、M08 蒙太奇），与即梦同图对比后择优上时间线。

### 国内站路线速查

| 路线 | 文生图 | 图生视频 | 说明 |
| --- | --- | --- | --- |
| **A** | [即梦](https://jimeng.jianying.com/) | 即梦 | 一站式；中文画面 + 剪映衔接。 |
| **B** | 即梦或可灵 | [可灵](https://klingai.kuaishou.com/) | 高光镜追求运镜时用可灵出视频。 |
| **C** | 通义万相、Liblib 等 | [海螺](https://hailuoai.com/)、[Vidu](https://www.vidu.cn/) 等 | 单平台排队或审核异常时的对照备选。 |

### 扩展：国际站冲高光（可选）

> **与二选一关系**：仅约 200 元且单开即梦时，**本节整条可跳过**；有额外预算且能稳定使用国际站时再启用。

| 角色 | 工具 | 用途 |
| --- | --- | --- |
| **主站** | 即梦 + 剪映 | 绝大部分镜头；中文 HUD；剪辑与字幕。 |
| **辅站** | 可灵（积分/会员） | 少量高光镜，与即梦同图择优。 |
| **冲高光（可选）** | [Midjourney](https://www.midjourney.com/) + [Runway](https://runwayml.com/) 或 [Luma](https://lumalabs.ai/) | 少量定妆图 + 5～10s 图生视频（材质、体积光）；**正文中文仍在即梦或剪映中加**，避免 MJ 乱字。 |

**预算量级（参考，以官网为准）**：国内即梦 + 可灵多为 **每月数百元人民币**；MJ + Runway 多为 **每月数十美元**。赛期建议 **先跑通即梦（+ 可灵）全片**，再视需要加开国际站 **只重做关键镜**。

**国际站落地注意**：网络可达、支付（双币卡 / PayPal）、**账号与发票归属**一人管理；国际站不可用时仍以国内站交片。赛前在 **即梦、可灵、Midjourney、Runway** 等协议中核对 **商用 / 比赛与宣传用途**；涉及儿童肖像时遵守各站内容与伦理规则。

### 组内定案（定稿后勾选）

- **二选一（约 200 元）**：仅 [即梦](https://jimeng.jianying.com/) + 剪映；可灵 **□ 不使用**。  
- **国内双开**：主站 即梦 + 剪映；辅站 可灵。  
- **国际冲高光**：Midjourney + Runway（□ 启用 / □ 不启用）。

### 定案前 1 小时「小样验收」

1. 取 **M01** 分镜，用已定主站（二选一为即梦）+ 同一套「角色锁」Prompt 出 **4 张图**，选 1 张定气质。  
2. 对该图做 **约 5s 图生视频**，动作写清：`slow push-in, subtle breathing, warm desk lamp`。  
3. **若已双开可灵**：同图在可灵再出 5s，与即梦并排择优；单站即梦则跳过。  
4. 检查 **手脸、手环中文可读、光影温情**；双开则择优上剪映时间线。
