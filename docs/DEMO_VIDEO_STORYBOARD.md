# AI 大赛演示片 — 分镜稿（温情向）

> 产品定位：**充满温情与关爱的陪伴**，弱化「监控」语感；画面与字幕优先使用「陪伴」「关注」「一起呼吸」等表述。  
> 与实机工程差异（长轮询 / 手机端音频等）见文末「成片与实机」说明。**分镜风格一致性与各镜扩写**见 **「分镜统一风格锚点」** 与 **M01～M08-2、M09** 表格；**即梦一条成片如何对应叙事、如何在剪映里拼**见 **「即梦制程：单片顺序与叙事对应」**。

---

## 全片基调

- **气质**：温暖、克制；科技服务于人，不冰冷。  
- **色板**：书桌冷白台灯 + 题纸灰白；焦虑段略压暗；治愈段转**琥珀金**主光。  
- **节奏**：前段渐紧 → 云端联动利落切镜 → 三端齐发 → 手环数字缓和收尾。  
- **孩子弧线（性格落幅）**：从 **要强、怕卡住** 带来的急躁与微坐不住，经安抚 **冲动降温**，再到 **眼神重新聚拢、自己啃题过关**；全片不演成「变了一个孩子」，而演 **在同一张书桌前学会收一收再继续**。

## 人物设定（定妆参考）

> **用途**：在生成视频前，先为 **孩子**、**父亲**、**母亲** 各出若干张 **定妆图**（建议：半身正面、45° 侧面、书桌场景中景各 1 张），全组选定后，**后续每一条文生图 / 图生视频 Prompt 都在开头粘贴「人物锁定」及孩子的「性格与行为锁定」**，减少多镜头脸崩、换装漂移。  
> **手环与穿衣**：手环 **佩戴手、表带颜色、表盘形状** 全片固定；T恤恐龙图案 **形状与颜色** 固定，避免每镜恐龙长得不一样。  

### 孩子（三年级男孩）

| 维度 | 详细描述（可直接拆进 Prompt） |
| --- | --- |

| **衣着** | **白色圆领短袖 T 恤**，版型略宽松、领口罗纹清晰；**胸前印有卡通恐龙图案**——建议固定为 **侧脸行走的绿系或蓝灰系恐龙**、**扁平插画风格**、面积约占胸前 **1/3**，不要每镜更换恐龙姿态。下装建议固定为 **深蓝或炭灰运动长裤**（或及膝运动短裤二选一，**全片只选一种**）。脚上若入画：**灰色家居拖鞋** 或 **白袜**，勿混用。 |
| **配饰** | **左手腕**佩戴 **浅蓝色方形表盘智能手环**，浅色窄表带（**全片固定，不更换**）。 |
| **性格内核** | **敏感、要强、怕卡住**：在熟悉房间里话不多，把劲头用在作业上；思路一断就容易 **急躁、自我埋怨**（心里急、不一定大声嚷），**不摔东西、不对大人吼**；被安抚后愿意配合深呼吸、回到题目，呈现 **能听劝、也想靠自己过关** 的孩子气。 |
| **情绪特征** | 偏内向的焦虑：**眉心聚拢、屏一下呼吸、轻咬下唇**；安抚后 **眉心松、嘴角放松**，神情从紧绷缓为安定。 |


**人物锁定**  
`全片同一男孩：东亚人，9–10岁三年级，黑色整洁短发有少量刘海，肤色暖黄健康，深褐色眼睛，白色圆领T恤胸前固定印有侧走绿色卡通恐龙图案（扁平插画风，面积约占胸前1/3），深蓝运动长裤，左手腕佩戴浅蓝色方形表盘智能手环，写字时右手握铅笔，写实摄影，电影自然光，全片体型比例一致。`

**性格与行为锁定（焦虑状态，用于 M01～M02-B、M06、M07）**  
`敏感要强，注意力与冲动特质，坐久易微焦躁，遇难题急躁皱眉咬唇揉太阳穴，不哭闹摔物，安抚后能回到题目专注演算。`

**性格与行为锁定（安定状态，用于 M08-2）**  
`同一男孩，冲动已降温，眉心平展，眼神重新聚拢在练习册上，嘴角放松不刻意微笑，铅笔尖悬停后落回纸面，专注克制，安静继续演算。`

> **三段式复用规则**：生成任何含孩子正脸/中近景的镜头时，**原文完整粘贴**「人物锁定」+ 对应状态「性格与行为锁定」，**不得缩写或改写**。无孩子正脸的极特写（M02-C 腕读、M03 手机粒子流等）跳过两个锁定块，直接写镜头描述。

**场景背景锁定（书桌场景各镜共用）**  
`宽幅实木学习桌，桌面宽大木纹清晰，原木色或深木色，搭配学习椅；桌面略凌乱，翻开的数学练习册、草稿纸、铅笔一支、少许橡皮屑；毛绒球放在近镜头侧桌角（焦虑段全暗，治愈段亮琥珀光）；臂式台灯从左或右前侧45°打光，背景书架虚化成色块。`

> **使用时机**：凡含书桌场景的镜头（M01、M02-A/B/C、M06、M07、M08-2），在「人物锁定」与「性格行为锁定」之后，追加粘贴本块；父母卧室镜头（M05、M08-1）**不使用**本块。

## 即梦制程：单片顺序与叙事对应

本片 **文生图 → 图生视频** 均在 **即梦** 完成，**剪映** 只做拼接、字幕、手环「陪伴中」字与简单调色。**一条即梦图生视频母文件 = 下表一行**；**连续动作分镜之间用尾帧图作起帧参考**（见 M02-A / M02-B / M02-C 各镜末尾的【尾帧操作】说明）。

| 成片拼接顺序 | 分镜编号 | 演示叙事对应 | 即梦产出说明 |
| --- | --- | --- | --- |
| 1 | **M01** | 叙事 1（建立场景） | 单条 3～4s；人物为主。 |
| 2a | **M02-A** | 叙事 1（急躁升温，HR 85→100） | 单条 3～4s；铅笔用力划掉几行算式（两拍递进），铅笔尖停住；生成后截取 **尾帧 `M02-A-tail.jpg`**。 |
| 2b | **M02-B** | 叙事 1（身体塌陷，HR 100→115） | 以 `M02-A-tail.jpg` 为起帧；左臂滑向桌面→下巴靠臂→长呼气→轻拨表带；生成后截取 **尾帧 `M02-B-tail.jpg`**。 |
| 2c | **M02-C** | 叙事 1（设备捕获峰值，HR 115） | 以 `M02-B-tail.jpg` 为起帧；腕读特写，数字定格，背景孩子静止屏息；本段无需再存尾帧。 |
| 3 | **M03** | 叙事 2（静默上云） | 单条；孩子可虚焦。 |
| 4 | **M04**（可选） | 叙事 2→3 过渡 | 不做则剪映中 **M03 直切 M05**。 |
| 5a | **M05** | 叙事 3.1（家长端） | 单条。 |
| 5b | **M06** | 叙事 3.2（毛绒球） | 单条；与 M05 / M07 在剪映里错开 ≤1.5s 做平行剪辑。 |
| 5c | **M07** | 叙事 3.3（星星机器人） | 单条；同上平行剪辑处理。 |

1. **书桌焦虑**：孩子戴着手环在书桌前写数学题；性格里 **要强、怕卡住** 被题目点燃——坐不住与急躁冒头，遇难题焦虑加重；手环侧显示心率 **115**（可用数字动画或 HUD 强调）。
2. **静默上云**：手机 App **不打扰孩子**，在后台将数据同步至 **腾讯云**（可用粒子流、云图标等抽象表现，避免过度绑定未授权 UI）。
3. **腾讯云激活联动**（三端同发，可快切或分屏）：
   1. **家长端**：隔壁房间父母的手机收到推送并开始震动（温和通知，非刺耳警报）。
   2. **毛绒球**：书桌上的 **微雪毛绒球** 收到云端指令，**瞬间亮起**治愈的**琥珀色暖光**，并缓缓淡入 **432Hz 钢琴曲**（可用音波可视化表现「声光一体」）。
   3. **星星机器人**：同时收到指令，**表情灯闪烁**，以特教老师般温柔语气主动开口：「小主人，写作业累了吧？我们先和毛绒球一起深呼吸三次吧。」
4. **安顿与继续**：声光与父母关注到位后，孩子呼吸放缓、心率逐步回落，冲动与焦躁 **先降温**；神情从紧绷转为安定，眼神重新 **聚拢在数式** 上，**停笔片刻后再次演算**，在草稿上试写几步、划改一两行，最终 **自己想通并完成** 这一小题。成片落点强调：**被温柔接住之后，仍能靠自己回到题目里，把困难一步步走过去**（多动冲动未消失，但学会在书桌前 **收一收、再想办法**）。

**一句话收束**：这是 **物联网 + 特教 AI** 的全方位闭环，也是产品希望对外传达的 **终极形态与核心壁垒**。

## 分镜统一风格锚点（各镜共用）

全片生成（文生图 / 图生视频）时 **每条 Prompt 除人物锁定与孩子的性格与行为锁定外**，建议重复或化用下列锚点，减少「有的像纪录片、有的像广告」的跳tone：

| 项 | 约定 |
| --- | --- |
| **影像气质** | **温情纪实 + 轻微电影感**；写实肤质与织物纹理；避免过度磨皮、避免网红滤镜；儿童表情 **克制真实**，不做夸张鬼脸。 |
| **色温** | 孩子书桌：**中性偏冷台灯主光**（约 4800–5600K）+ 环境弱暖反射；焦虑镜（M02）可 **整体降 1/4 档曝光**；治愈段（M06 起）引入 **琥珀金**（约 2800–3500K）与冷台灯的 **小面积对比**，不要整屏糊成单色。 |
| **对比与颗粒** | 中低对比、暗部 **微微抬起**（保留细节，不死黑）；可带 **极轻胶片颗粒**（统一一种，全片一致）。 |
| **景深** | 以 **浅景深突出主体**（孩子脸 / 手环 / 毛绒球 / 父母脸）为主；全景时景深略收，仍保持层次。 |
| **运镜** | 以 **慢推、轻摇、静止长镜头** 为主；除 M02、M08 外 **少用急甩镜头**；全片 **无手持剧烈晃动**（可用极轻 stabilized micro-movement）。 |
| **人物** | 孩子与父母 **须与《人物设定》定妆一致**；同一镜内 **五官比例、发型分区线、T恤恐龙轮廓** 与定妆图对齐。孩子除外形外须符合 **「孩子」小节** 中的「性格内核」「外显行为」「情绪出口」「全片体现要点」，焦虑与坐不住 **克制、不离书桌叙事**。 |

| **人物与动作（可选入画）** | 孩子 **不出正脸也可**：仅 **入画下巴到肩** 或 **眼神余光被光吸引** 的微动；若出正脸，表情从 M02 焦虑 **松一线**：**眉心纹略展、嘴唇微启**。性格线：冲动暂缓，注意力被新刺激 **短暂吸住** 但仍 **不离开椅面**；若加微动，**脚尖不再点地**。 |

### M08-1｜闭环快切（约 4～5s）

> **本段为多刀拼接**：在即梦分别生成每一刀，导入剪映后依序拼接，每刀 0.6～1.0s。无需尾帧衔接（各刀场景不同，剪辑转场承担连续性）。

| 项目 | 内容 |
| --- | --- |
| **风格锚点** | **快切但同一调色 LUT**；每刀 **0.6～1.0s**，避免 MV 式乱闪；转场用 **圆形光晕 / 琥珀色 wipe** 与 M06 呼应。 |
| **刀次顺序** | ① 云粒子（接 M03 色系，0.6s）→ ② 父亲脸（**0.5s**，关切已落地，眉略展眼神稳，面部平滑年轻与定妆一致）→ ③ 母亲脸（**0.5s**，同上）→ ④ 毛绒球（**琥珀呼吸一拍**，0.8s）→ ⑤ 机器人（**微笑稳定帧**，0.6s）。 |
| **运镜** | 以 **切** 为主，少甩镜；无推近，留给 M08-2 收尾。 |
| **音效** | 钢琴渐入，**前半段铺底**；与 M08-2 衔接处 **0.3～0.5s 轻静音** 过渡。 |
| **即梦提示词** | 每刀各自生成：**刀①** `柔和科幻粒子云，青白色调，缓慢漂移，极克制，写实电影感`；**刀②③（父母）** 首行粘贴**人物锁定（父母）**，随后接 `暖台灯下，表情从关切转为略松，眉间舒展，眼神稳定，写实电影感，无衰老妆`；**刀④（毛绒球）** `书桌毛绒球琥珀暖光呼吸一拍，光晕柔和，写实近景`；**刀⑤（机器人）** `桌面小机器人屏幕脸微笑稳定帧，LED表情柔和，写实电影感`。 |

### M08-2｜安定与继续（约 4s）

> **接续 M08-1 尾**：M08-1 最后一刀（机器人微笑帧）与本镜之间做 **0.3～0.5s 轻静音 + 淡入**，给观众「吸一口气再落回纸面」的空隙。本镜为全片情绪落点，节奏放缓，单条生成。

| 项目 | 内容 |
| --- | --- |
| **风格锚点** | 同一调色 LUT；节奏从 M08-1 快切**切换为长镜**；冷白台灯主光 + 琥珀余光映书桌一角（M06 琥珀光在画面边缘仍可感知）。 |
| **场景** | 孩子书桌，同 M01/M02 机位；练习册仍在桌上，可见铅笔横划痕迹（与 M02-A 形成视觉呼应）。 |
| **人物与动作** | **胸上构图**：双眼 **轻闭约 0.8s** 再睁开；睁开后 **眉心平展**、颊红晕比 M02 **退 30%**，眼神 **重新聚拢在数式** 上；铅笔尖 **悬停一拍后缓缓落回纸面**，开始演算；可有 **极轻点头**，表示「愿意继续试」；**嘴角放松** 不刻意微笑。 |
| **手环数字** | **115 → 约 95** 动画 **2s 缓降曲线 ease-out**；数字颜色从 **略警淡琥珀** 过渡到 **青绿安定色**（低饱和，勿赛博霓虹）；数字在剪映后期叠加，即梦生成时手环仅显示安定光晕。 |
| **运镜** | 静止或 **极慢微推近**（dolly-in 0.2 单位速度），结束在眼与铅笔尖之间的构图。 |
| **音效** | 钢琴 **一个完整和弦** 收束；**环境声回归** M01 量级（铅笔尖轻划纸声可见）。 |
| **即梦提示词** | 首行粘贴**人物锁定（孩子）**与**性格与行为锁定（安定状态）**，随后接：`东亚男孩坐在书桌前，双眼轻闭片刻后睁开，眉心平展，眼神重新聚拢在练习册数式上，铅笔尖悬停后缓缓落回纸面开始演算，嘴角放松，肩线自然下沉，手环表盘安定青绿光晕，冷白台灯侧光，琥珀余光映书桌一角，极慢微推镜，写实电影感，克制温情，8K` |

## 成片与实机（供答辩混剪）

> 下表列出演示片中的视觉/叙事表达与工程实际实现之间的差异，以及答辩时推荐的口径。**影响程度**：低 = 口播不提即可，中 = 需提前准备话术，高 = 需主动说明边界。

| 演示说法 | 当前工程实现 | 影响 | 建议话术 / 处理方式 |
| --- | --- | :---: | --- |
| 云端 MQTT 实时推送到毛绒球 | HTTP **长轮询**（`GET /device/<id>/cmd?wait=25`），延迟约 0–25 s | 低 | 动画写「云端联动」，字幕用「云端一指触达」，不具体说协议 |
| 毛绒球发出 432 Hz 疗愈音频 | 432/528 Hz 音频主要在**家长手机端**（`just_audio`）播放，球本身**无扬声器** | 低 | 画音波从手机流向球，或仅展示球光效 + 环境钢琴音；口播不提球端发声 |

| 一键发布小红书 | 小红书**无官方开放接口**，当前实现仅能生成脱敏草稿文案 + AI 配图（`/share/xiaohongshu_draft`、`/share/generate_image`），不能自动发布 | 低 | 演示截图草稿界面，口播说「一键生成草稿，家长确认后发布」；不演示「发布」按钮 |
