# AI 短片生产 — 通用元提示词（分镜稿 · 资产清单 · 视频生成）

> **定位**：本文档**不绑定任何具体剧本或仓库项目**。将下列各节整段复制给 AI，用于：① 从零撰写**分镜稿** Markdown；② 从已有分镜稿派生**资产与道具提示词清单**；③ 在任意工具链中组织**文生图 / 图生视频**与后期分工。  
> **使用方式**：按需复制对应「可执行提示词」块；在对话中自行提供**片名、时长、画幅、风格、人物与道具设定**等变量，勿假设模型读过你的私有文件。

---

## 一、可执行元提示词 — 生成分镜稿（Storyboard / Shot List）

把从「你是资深…」到「自检清单」的整段交给模型。

你是资深广告 / 短片导演兼制片文档编辑。请根据用户在对话中提供的**创意说明**（主题、受众、片长或镜头数上限、画幅、写实 / 动画倾向、禁止项等），输出一份**独立完整**的**分镜稿 Markdown**，用于后续 AIGC 出图与剪辑。

### 必须遵守

1. **结构清晰**：至少包含 —
   - **项目总览**：片名（中英可选）、目标时长与镜头数、画幅比、风格一句、色板与情绪走向、音乐主线、**旁白声线设定**（统一声线 / 分角色 / 无旁白，全文一致）；
   - **人物与关键道具设定**（表格或分条，含可视觉化的外貌 / 服装 / 道具状态约束）；
   - **逐镜头分镜表**；
   - **制作备注**（声音、字幕、品牌 / 法律注意点若有）。

2. **逐镜头字段统一**：每个镜头包含以下字段（按镜头类型勾选适用项）：

   | 字段 | 说明 | 普通叙事镜 | 概念 VFX 镜 |
   |------|------|:---:|:---:|
   | 编号与标题 | 格式：`镜头 NN — 小标题` | ✓ | ✓ |
   | 时长 | 秒数，可加累计 | ✓ | ✓ |
   | 景别 | 大全/全/中/中近/近/特写/微距 | ✓ | ✓ |
   | 运镜 | 推/拉/摇/跟/手持微晃/静止/呼吸式等 | ✓ | ✓ |
   | 镜头内容 | 谁在哪做什么（事实陈述） | ✓ | ✓ |
   | 画面描述 | 视觉细节、光影、关键道具状态约束 | ✓ | ✓ |
   | 旁白 / 字幕 | **旁白**（画外音文字 + 声线说明）与**字幕**（屏幕叠加文字）分开标注；有对白台词的注明角色 | ✓ | — |
   | 台词 | 角色对白逐句列出，标注说话角色；含对口型需求时加「【需对口型】」 | 按需 | — |
   | 音效 | 具体描述 | ✓ | ✓ |
   | 音乐情绪 | 与全片音乐主线挂钩 | ✓ | ✓ |
   | VFX 说明 | 描述概念可视化元素（全息 / 数据光线 / HUD 等）的视觉规则，注明「仅观众可见 / 角色可见」 | — | ✓ |
   | 后期分工 | 标注哪些元素须后期贴图 / AE 合成 / 跟踪，不依赖文生图 | 按需 | ✓ |

3. **镜头类型说明**：
   - **叙事镜**：真实场景中的人物行为，文生图可直接还原。
   - **概念 VFX 镜**：含抽象数据可视化（心率全息 HUD、数据信号光线、云端光球等），文生图只出基础底层，VFX 元素由后期 AE / 剪映合成叠加；在分镜中须说明 VFX 元素是「叙事层（观众可见）」还是「剧情内真实发生」，避免演员表演与可视化矛盾。
   - **转场连接镜**：以同一视觉元素（光线 / 声音 / 运镜）衔接相邻两镜；分镜中注明「与镜头 XX 以剪辑相连，非同框」。

4. **生图提示词（可选章节）**：若用户需要直接喂给文生图模型，为每个镜头提供**中文要点** + **English prompt**；并给出全片可复用的**风格串（Style Token）**、**负向串（Negative Token）**、**质量串（Quality Token）**各一行，说明可拼接到每条 EN 末尾。七要素写法建议：**风格 · 构图 · 主体 · 背景 · 细节 · 光影色调 · 质量**。

5. **图生视频与后期（可选章节）**：简述推荐流水线；列每镜头**建议的图生视频时长与运镜**；声明**含文字的 UI、精确数字、品牌 Logo** 尽量后期贴图；**台词对白镜头**标注是否需要对口型。

6. **不自相矛盾**：
   - 时间轴相加与目标总时长一致；
   - 同一道具（颜色、左右手佩戴、屏幕显示状态）全片前后一致；
   - 全片色温弧线（冷/暖变化的关键镜头节点）前后一致；
   - 概念 VFX 的视觉规则（光线颜色、HUD 颜色码、可见范围）全片一致。

7. **信息不足时**：先列出 **3～7 条澄清问题**再输出；若用户要求「直接给一版」，则在文档中用 `【待确认】` 标注假设项，并在文档末尾集中列出所有假设。

### 建议输出目录（Markdown 标题层级示例）

- `# 片名 — 分镜稿`
- `## 项目总览`
- `## 人物与道具设定`
- `## 逐镜头分镜表`（`### 镜头 01 — …` 逐条展开）
- `## AI 生图提示词（可选）`
- `## 图生视频与剪辑说明（可选）`
- `## 制作备注`

### 自检清单（输出前逻辑核对）

- [ ] 每镜时长与字段齐全，总时长可加总校验
- [ ] 人物 / 道具视觉约束可被执行，无「随意发挥」的模糊关键物
- [ ] 旁白声线设定在项目总览中已说明，且逐镜一致
- [ ] 台词对白已标注说话角色；需对口型的镜头已加【需对口型】
- [ ] 概念 VFX 元素已标注「观众可见 / 剧情内真实」及后期分工
- [ ] 全片色温弧线（转折镜头）已在制作备注中标注
- [ ] 含文字 UI / 精确数字 / Logo 的镜头已注明后期贴图
- [ ] 若含 EN prompt，风格与负向与用户的写实 / 动画取向一致
- [ ] 敏感表述（医疗、儿童、监控等）符合用户给的合规边界

## 二、可执行元提示词 — 从分镜稿生成「资产与道具提示词清单」

把从「你是影视与…」到「自检清单」的整段交给模型。用户在对话中提供：**输入** = 分镜稿全文或路径描述；**输出** = 希望生成的资产文件名或「仅输出 Markdown 正文」。

你是影视与 AIGC 工作流顾问。请**只依据**用户提供的**分镜稿**（Markdown 或结构化文字），生成一份**独立的**《AIGC 资产与道具提示词清单》Markdown，用于文生图 / 图生视频前的**角色定妆、多表情参考、关键道具单品、场景核心词**一致性管理。

**不要**逐条复制分镜里「逐镜头完整生图长 prompt」整章；资产清单只承担**可复用的资产库**，与「按镜头出图」分工。

### 必须遵守的全局规则

1. **信息来源**：人物、服装、道具、场景元素必须可在用户提供的分镜中找到依据；**场景小节禁止**脑补分镜未写的陈设。

2. **视觉风格**：对齐分镜中的全片基调（实拍 / 动画 / 3D 等以分镜为准）。若分镜要求真人写实，则在资产 EN 中显式写 `photorealistic, live-action, natural skin texture` 等，并排除 `anime, cartoon, illustration, 3D render` 等与分镜冲突的项。

3. **定妆与道具单品背景**：默认 `pure solid white background`，无杂物，便于抠像。若分镜明确要求定妆带环境光，在「使用建议」中单列**白底定妆 vs 正片实景**分工。

4. **人物锁定段落（Character Lock）**：除「基础定妆（EN）」外，额外为每位主要角色提供一条**可内联到任意镜头 prompt 首行**的简短锁定描述（30–60 词，含年龄、国籍、发型、服装关键词、手环或特殊道具约束）。格式示例：
   ```
   [Character lock – 角色名] same character throughout: [年龄/国籍/性别/发型/服装/关键道具/手腕/佩戴约束], photorealistic, cinematic light.
   ```

5. **穿戴设备 / 屏幕 / HUD**：一切发光、屏显、振动、**左右手佩戴**等，**仅以当前分镜为准**；多状态道具用**状态 A/B/C** 并标注**镜头编号**。含文字、数字的界面一律建议**后期贴图 / 跟踪**，资产条目中描述光效与留白即可，不要让模型生成可读文字。

6. **颜色码道具**（如多角色颜色区分的手环、衣物等）：明确列出颜色 → 角色的绑定表，并在每条 EN 中显式写颜色词（如 `BLUE wide strap`），负向词中写明禁止串色（如 `orange strap, green strap`）。

7. **已有实物**：若分镜写「以上传实拍为准」，清单中简要 EN + **醒目标注「以上传实拍图为准」**，不伪造细节。

8. **质量词策略**：资产清单正文可约定**不含** 8K、masterpiece 等堆砌（由团队按模型再定）；若分镜要求在镜头级保留质量词，资产章节约束仅写「镜头级见分镜」。

### 建议输出 Markdown 结构

1. 标题与摘要（片名沿用分镜；一行说明用途）。
2. 全局设定：风格 + 白底策略 + **统一 Negative** + 颜色码绑定表（若有）+ 是否含质量词。
3. **一、角色画面提示词**：每角色 — 维度表 + **基础定妆（中）** + **基础定妆（EN）** + **人物锁定段落（EN）**。
4. **二、角色多表情独立定妆**：用法说明；仅面部；`[role base]` + `facial expression only` + `head-and-shoulders portrait` + 白底。
5. **三、道具画面提示词**：P 系列编号；多状态道具对齐镜头号；颜色码道具标注对应角色。
6. **四、场景画面提示词**：仅分镜已写空间与元素 + 镜头索引；VFX / 数字空间场景单独列。
7. **五、使用建议**：锁妆 → 表情 → 道具叙事硬约束 → 颜色码铁律 → 场景引用 → UI 后期 → 实物参考图导入。

### 语言与格式

- 说明以中文为主；可投喂模型的 **EN** 用反引号或独立行；GFM 表格；勿用 HTML。

### 自检清单

- [ ] 无分镜未出现的设定
- [ ] 道具颜色、左右手、屏显规则全文一致
- [ ] 多状态已对齐镜头号
- [ ] 颜色码绑定表已列出，且每条 EN 已写颜色词 + 负向排异
- [ ] 每位主要角色均有「人物锁定段落」
- [ ] 未粘贴整章逐镜头长 prompt

## 三、通用片段 — AI 视频生成工作流（可直接拼接或微调）

以下**不依赖任何剧本**，按项目替换 `{…}` 即可。

### 3.1 推荐流水线（叙述用，可放进分镜「图生视频」节）

1. **锁一致性**：角色 / 关键道具先出**定妆参考图**（或实拍参考图），固定 seed 或模型「角色」功能；将「人物锁定段落」写入每镜 prompt 首行。
2. **出首帧（与必要尾帧）**：按分镜用文生图生成；**画面变化大**（如色温从冷到暖、道具状态切换、VFX 出现）的镜头出**首帧 + 尾帧**，再走首尾帧图生视频。
3. **图生视频**：单段时长受工具限制时，**拆段生成再剪辑拼接**；运镜描述尽量短、可执行；含台词的镜头在图生视频后单独走**对口型**。
4. **VFX 空镜**：全息 HUD、数据光线、云端可视化等**概念镜头单独生成光效素材**，在剪辑软件与实拍 / 写实素材合成叠加。
5. **剪辑合成**：对白 / 旁白 / 音乐 / 调色 / 字幕 / **含字 UI** 在剪辑软件完成；全片套统一 LUT 或调色节点，按色温弧线节点做冷暖过渡。

### 3.2 镜头类型与即梦（Dreamina）操作速查

| 镜头类型 | 即梦推荐模式 | 关键操作要点 |
|------|------|------|
| 普通叙事镜（单一画面） | 图生视频（单帧） | 首帧定稿后拖入图生视频 |
| **变化类镜头**（色温切换 / 道具状态突变 / 人物动作幅度大） | **首尾帧**图生视频 | 首帧 + 尾帧各出一张，走首尾帧模式；变化节点写进运镜描述 |
| 台词对白镜（角色开口说话） | 图生视频 + **对口型** | 先出图生视频，再单独走对口型；台词文本须提前准备，标注说话角色 |
| **概念 VFX 空镜**（全息 HUD / 数据光线 / 信号可视化） | 文生图 → 图生视频（VFX 素材） | 仅生成光效底层；叠加文字 / 数字 / 精确曲线全在剪辑完成 |
| 长镜头（>7s） | 图生视频 **拆段** | 5s + 延长，或按动作节点拆 2–3 段拼接 |
| **剖面 / 建筑截面合成**（展示隔墙两侧同一时刻） | 多图参考 → 图生视频 | 用两张已有侧面参考图；提示词写「architectural cross-section / cutaway doll-house view」+ 横向并排两房间 + 中间竖直隔墙；UI 元素后期叠加；若 AI 始终无法生成，在剪辑软件手动横拼两张单房间帧 |

### 3.3 图生视频 — 提示词模板（中英文可混用）

**基础单帧模板**
```text
[人物锁定段落 / Character lock – 角色名] +
画面：{主体动作与位置}，{环境一句话}，{关键道具状态}，
运镜：{推 / 拉 / 摇 / 跟 / 手持微晃 / 呼吸式推拉 / 静止等，择一或组合}，
风格：photorealistic, live-action, real people, cinematic, natural skin texture, shallow depth of field,
负向：anime, cartoon, illustration, 3D render, CGI, plastic skin, doll-like, distorted hands, extra fingers, text artifacts, watermark
```

**首尾帧变化模板（色温 / 状态切换）**
```text
首帧：{冷调 / 道具关闭 / 状态 A 描述}
尾帧：{暖调 / 道具亮起 / 状态 B 描述}
变化描述：{从…到…，光晕由内向外扩散 / 色温冷转暖 / 数值上升等}
运镜：{运镜描述}
风格：photorealistic, live-action, real people, cinematic, natural skin texture,
负向：{统一负向串}
```

**概念 VFX 空镜模板（数据光线 / 全息 HUD）**
```text
画面：{光效形态描述：纤细 / 丝滑 / S形曲线 / 直线 / 脉冲扩散 / 半透明全息气泡等}，
光效规则：{颜色，克制不华丽，无丝带无繁复粒子拖尾 / 整帧不变色仅局部光晕等}，
背景：{暗底环境，光效为画面视觉焦点}，
负向：ribbon trails, ornate particle effects, neon oversaturation, garbled text, whole-frame color wash, anime, 3D render
```

**对口型台词备注**
```text
台词文本："{角色名}：{逐句台词，语速与情绪标注}"
声线要求：{温柔女声 / 特教老师语调 / 温柔轻声等}
操作：先完成图生视频，再在对口型功能中载入台词文本与参考图
```

### 3.4 文生图（镜头首帧）— 可复用 Token 模板

在分镜或单镜头 prompt 末尾按需拼接（**按项目改写**）：

**风格串示例（真人电影感）**

`photorealistic, live-action film still, shot on ARRI Alexa, 35mm lens, cinematic warm storytelling, real human actors, natural skin texture, shallow depth of field, soft volumetric light, subtle film grain, 2.39:1 anamorphic`

**风格串示例（温情纪录片感，适合教室 / 日常场景）**

`photorealistic, live-action documentary warmth, cinematic natural classroom or interior light, real human actors, natural skin texture, medium contrast, slight film grain, shallow depth of field on subject`

**负向串示例（防卡通与脏手）**

`anime, cartoon, illustration, 3D render, CGI, plastic skin, doll-like, video game, extra fingers, distorted hands, text artifacts, watermark`

**质量串示例（可选，按模型敏感度删减）**

`masterpiece, ultra-detailed, 8K, sharp focus, professional color grading, highly detailed textures, award-winning cinematography`

### 3.5 后期与 AIGC 分工原则（通用）

| 内容类型 | 推荐处理方式 | 原因 |
|------|------|------|
| 可读文字（手机推送 / App UI / 输入框文字） | AE / Figma / 剪映贴图 | AI 易生成乱码或无关汉字 |
| 精确数字（心率数值 / 计数器） | 剪映 / AE 数字动效 | AI 无法保证数字精确且动态 |
| 品牌 Logo / 产品名称 | 后期叠加 | 版权与精度双重风险 |
| 心率曲线 / 折线图 / 数据图表 | 剪映 / AE 绘制 | AI 图表随机，不可重现 |
| 全息 HUD 精确内容 | 后期，AI 仅出光效底层 | 同上 |
| 台词对白口型 | 图生视频后走对口型功能 | 口型与台词匹配需专项工具 |
| 旁白 / 音乐 / 音效 | 剪辑软件全权负责 | AI 视频不含音频 |
| 色温统一 LUT | 全片统一调色节点 | 跨镜色温弧一致性 |
| 剖面 / 两房间横拼 | 剪辑软件横拼 + 中间添墙（备用） | AI 剖面合成不稳定时的兜底方案 |

### 3.6 色温弧线管理（适用于有情绪转折的短片）

全片若存在「冷基调 → 暖基调」的情绪转折，需在分镜与出图时统一管理：

- **在项目总览**：明确写出「色温转折关键镜头编号与方向」（例：前段冷青灰，镜头 XX 完成由冷转暖，后段琥珀暖金）。
- **在分镜对应镜头**：在「画面描述」中写明「全片色温转折点在此」，并在 EN prompt 中显式写出色温变化（如 `shifting from cool cyan to amber warm gold`）。
- **在即梦操作**：色温转折镜走**首尾帧**；后期在剪辑软件对全片分段调色（冷段 LUT + 暖段 LUT + 转折镜过渡节点）。
- **在 EN prompt 中**：冷调段加 `cool cyan-gray, desaturated, low color temperature`；暖调段加 `amber warm gold, diffuse glow, healing warmth`；避免冷暖描述混用在同一段 prompt 里。

### 3.7 常见风险（检查表）

- [ ] **手部与手指**：特写镜头负向加强 `distorted hands, extra fingers`，或后期修补。
- [ ] **同一角色跨镜头脸型漂移**：固定参考图与 seed 策略；每镜 prompt 首行粘贴人物锁定段落。
- [ ] **颜色码道具串色**（多角色颜色区分场景）：每条 EN 显式写颜色 + 负向排异；出图前一次性定案，不可中途修改。
- [ ] **屏幕 / HUD 乱码**：手环屏幕、手机界面、数字 HUD 的负向词加 `screen with numbers, lit display, garbled text`，并在提示词中写「screen completely black / blank glow for post text」。
- [ ] **夜景 / 日景混用**：室内夜景项目每条 prompt 必须写 `at night, pitch-black windows, no daylight, no outdoor sunlight`，避免模型引入天光。
- [ ] **长镜头超工具单段上限**：拆段 + 动作衔接点写在分镜里；衔接点首尾两帧的人物姿势 / 道具位置须一致。
- [ ] **声音与画面不同步**：对白镜单独列录音 / 对口型节点；对口型台词文本提前准备。
- [ ] **概念 VFX 与真人写实风格冲突**：在同一镜头中混合真人与 VFX 时，分两层生成（真人底层 + VFX 叠加层），不尝试在一条 prompt 里同时控制两者精度。
- [ ] **剖面合成失败**：若 AI 无法可靠生成两房间剖面，立即切换兜底方案（剪辑软件横拼 + 画墙）；不在 AI 上反复消耗时间。
